# Dayflow HRMS Frontend

React + Vite frontend connected to the FastAPI backend.

## Start
```bash
npm install
npm run dev
```

The frontend uses `http://localhost:8000` by default. To override it:
```bash
cp .env.example .env
# set VITE_API_URL=http://localhost:8000
```

## Demo logins
- Admin: `OIARDE20220001` / `Welcome@123`
- Employee: `OIRISH20230001` / `Welcome@123`

Make sure the backend is running before signing in.
